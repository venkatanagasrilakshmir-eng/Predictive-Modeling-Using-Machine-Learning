# Predictive-Modeling-Using-Machine-Learning
## Objective
Build a machine learning model to predict outcomes using supervised learning techniques.

## Algorithms Used
- Logistic Regression
- Decision Tree
- Random Forest

## Features
- Data preprocessing
- Model training
- Model evaluation
- Confusion matrix visualization
- ROC curve analysis

## Results
Achieved high accuracy using Random Forest model.

## Tech Stack
Python, Pandas, Scikit-learn, Matplotlib, Seaborn
